# P138 我是大廚 — I'm the Chef

Web Version: **V0.007** · Standard: **SBI-P-SDS v3.4** · P138-DS v1.0

## 關卡
1. 荷包蛋
2. 香嫩炒蛋
3. 蒜香清炒高麗菜：洗菜、切菜、炒蒜、炒青菜、撒鹽、翻炒、盛盤。

直接開啟 `index.html` 或部署至 GitHub Pages。原生 HTML/CSS/JavaScript，無登入、無資料庫、無需安裝套件。

## 第三關操作
從上排櫥櫃取得高麗菜、蒜頭、砧板、菜刀、炒鍋、油、鹽、鍋鏟、餐盤；將炒鍋放上爐、餐盤放到右側出菜區。洗菜時先開啟水流並拖過至少 8 個區域，再沿砧板切線切高麗菜與蒜頭。將油倒入炒鍋，開火並先炒蒜，再放高麗菜，使用鍋鏟翻炒並撒鹽，最後盛盤計分。滑鼠、觸控、按鍵點選提供基本替代。

注意：本遊戲模擬參數不代表真實食品安全／烹調標準。洗菜百分比不表示真實殺菌。
