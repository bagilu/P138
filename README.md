# P138 我是大廚 / I'm the Chef

**Web Version:** V0.002  
**SBI-P-SDS:** v3.4 (2026-10-20)  
**技術：** HTML / CSS / 原生 JavaScript / SVG。純前端、無 npm、無 Supabase。

## 快速開始

將 ZIP 解壓縮後，開啟 `P138_ImTheChef/index.html` 即可遊玩；或將 **資料夾內** 的內容上傳至 GitHub repo 根目錄，開啟 GitHub Pages（Deploy from branch / main / root）。本版不需要執行 SQL，也不需要建立 `config.js`。

## 遊戲操作 V0.002

- 選擇關卡 001 荷包蛋 或 002 香嫩炒蛋；切換時重設當前料理。
- 底部物品架可以水平捲動，內有食材、調味料和廚具。**拿起物品不扣分**，但將非指定物品拖入鍋子／攪拌碗並放開會記錄誤用，每次扣 10 分，累計最多扣 50 分。
- 油瓶拖進鍋中持續按住倒油，流速 2 mL／真實秒；油量不依遊戲倍速加速。
- **荷包蛋**：加油、開火預熱、雞蛋拖入鍋中、注意熟度、鍋鏟拖入鍋中盛盤，再按完成出餐。
- **香嫩炒蛋**：拖兩顆雞蛋到攪拌碗→按住「攪拌蛋液」或拖打蛋器到碗上→混合達 80%→加入油、預熱→點「將蛋液倒入鍋中」→將鍋鏟拖入鍋中來回移動翻炒（鍵盤聚焦鍋鏟按 Enter 亦可）→按「用鍋鏟盛盤」→完成出餐。
- 背景音樂為 Web Audio API 即時合成的原創短旋律（無外部音樂檔），由使用者點擊後開始播放；可獨立開關音效及調整音量。
- 鍵盤：各物品可以 Tab 聚焦，按 Enter/空白使用；混合/盛盤亦有按鈕。

## V0.002 範圍與限制

- 新增料理選單、兩種料理、16 種物品、物品誤用扣分、炒蛋攪拌與翻炒、可切換音樂音效。
- 料理數值為**遊戲示範數值**，不保證真實食品安全或烹調品質；火候／攪拌／評分是簡化模型。
- 不儲存個人紀錄，不使用資料庫、登入、外部 CDN 或外部音源。
- 平台仍以 GitHub Pages 提供靜態網頁為主；Android 桌面圖示沿用既有 SVG/PNG。

## 專案檔案

- `index.html` — 主畫面與遊戲操作區
- `styles.css` — RWD 2D 廚房與操作視覺
- `app.js` — 狀態、時間模擬、拖曳、評分
- `assets/icon.svg` — 專屬 icon / favicon
- `manifest.webmanifest` — 網站捷徑中繼資料
- `config-sample.js` — 本版僅為規範預留，無敏感參數
- `database/` — 明確標註無資料庫物件，SQL no-op
- `docs/` — 規格與合規檢查報告

## 部署／安全

本版不使用 Supabase，也不呼叫 REST/Table API；無任何權限設計、密碼或敏感資料需要配置。未來加上登入／資料庫時，必須先依 v3.4 新增隔離 schema、RLS、RPC、逐項 Grants、Auth/P130 分工與完整健康檢查；不可直接將資料表暴露給前端。

**Web Version 規範：** `index.html` 顯示 `V0.002`，`styles.css?v=0.002` 與 `app.js?v=0.002` 同步，變更前端時均應遞增。
