# P138 我是大廚 / I'm the Chef

**Web Version:** V0.001  
**SBI-P-SDS:** v3.4 (2026-10-20)  
**技術：** HTML / CSS / 原生 JavaScript / SVG。純前端、無 npm、無 Supabase。

## 快速開始

將 ZIP 解壓縮後，開啟 `P138_ImTheChef/index.html` 即可遊玩；或將 **資料夾內** 的內容上傳至 GitHub repo 根目錄，開啟 GitHub Pages（Deploy from branch / main / root）。本版不需要執行 SQL，也不需要建立 `config.js`。

## 遊戲操作

1. 使用滑鼠或手機觸控拖曳**沙拉油瓶**到鍋子中央，**持續按住／長按**倒油；時間愈長，油量愈多（模擬流速 2 mL/秒）。鍵盤聚焦油瓶，按 Enter/空白可增加 2 mL。
2. 點選 **小火／中火／大火**；鍋溫依模擬時間逐步變化，不會立即升至目標值。
3. 將 **雞蛋**拖到鍋子中央，放開即可下鍋；鍵盤 Enter/空白可下蛋。
4. 等待蛋白熟度提升，必要時調整火力。可用「模擬速度」調整等待時間。
5. 將 **鍋鏟**拖曳到鍋子中央，放開後盛盤，再按 **完成出餐** 查看六項條件的逐項評分；鍵盤 Enter/空白也支援。
6. 「重新挑戰」重新初始化所有狀態。

## V0.001 範圍與限制

- 第一關荷包蛋（全流程）；鹽巴／蔬菜為後續菜色的視覺預留，**尚無操作功能**。
- 參數為玩法原型的**示意數值**：油量 3–8 mL、下蛋鍋溫 130–170°C、蛋白熟度 ≥95%、蛋黃 20–60%、下蛋後烹調時間 60–120 秒、蛋在鍋內時最高溫 ≤200°C。非真實食譜、食安或食品工程驗證值。
- 預設 3× 遊戲時間；溫度與熟度使用簡化離散模擬，非物理準確模型。
- 無登入、成績存檔或排行榜；關閉或重新整理即重置。
- 不需要網路或外部程式庫。SVG icon 同時用於 favicon 與 PWA manifest；部分 Android 啟動器對 SVG maskable icons 支援有限，若要完整跨平台安裝體驗，後續應補 192／512 PNG。

## 專案檔案

- `index.html` — 主畫面與遊戲操作區
- `styles.css` — RWD 2D 廚房與操作視覺
- `app.js` — 狀態、時間模擬、拖曳、評分
- `assets/icon.svg` — 專屬 icon / favicon
- `manifest.webmanifest` — 網站捷徑中繼資料
- `config-sample.js` — 本版僅為規範預留，無敏感參數
- `database/` — 明確標註無資料庫物件，SQL no-op
- `docs/` — 規格與合規檢查報告

## 部署／安全

本版不使用 Supabase，也不呼叫 REST/Table API；無任何權限設計、密碼或敏感資料需要配置。未來加上登入／資料庫時，必須先依 v3.4 新增隔離 schema、RLS、RPC、逐項 Grants、Auth/P130 分工與完整健康檢查；不可直接將資料表暴露給前端。

**Web Version 規範：** `index.html` 顯示 `V0.001`，`styles.css?v=0.001` 與 `app.js?v=0.001` 同步，變更前端時均應遞增。
